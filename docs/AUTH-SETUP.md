# Авторизация (PostgreSQL)

## Быстрый старт

PostgreSQL должен быть запущен (`brew services start postgresql@14`).

```bash
npm run setup   # миграции
npm run dev     # миграции + Next.js (миграции и так в pre-dev)
```

`.env.local` уже настроен. База: `enter_marketing` на `localhost:5432`.

## 1. PostgreSQL

Если базы нет:

```bash
createdb -h localhost -U postgres enter_marketing
```

## 2. Миграции

```bash
npm run db:migrate
```

## 3. Google OAuth

В [Google Cloud Console](https://console.cloud.google.com/) → Credentials → OAuth client:

- **Authorized redirect URIs:** `http://localhost:3000/api/auth/google/callback`
- Для продакшена добавьте ваш домен: `https://ваш-домен/api/auth/google/callback`

## 4. Gmail SMTP

Используйте **пароль приложения** Google (не основной пароль аккаунта).

## 5. Запуск

```bash
npm run dev
```

Страницы:

- Вход: `/login`
- Регистрация: `/register`
- Сброс пароля: `/forgot-password`
- Личный кабинет: `/profile` (только для авторизованных)

## Возможности

- Регистрация: email → код на почту → пароль + подтверждение
- Вход по email/паролю
- «Забыли пароль» → код → новый пароль
- Вход через Google

## Безопасность и данные

**Что хранится в PostgreSQL**

| Данные | Когда появляются | Когда удаляются |
|--------|------------------|-----------------|
| Email + хеш кода | После «Получить код» | Через **15 мин** или после успешной регистрации/сброса |
| Имя, пароль | Только после «Зарегистрироваться» | Не удаляются (аккаунт создан) |
| Сессия (JWT) | После входа / регистрации / Google | Через **30 дней** или «Выйти» |

Имя и пароль **не пишутся в базу**, пока человек не завершил регистрацию. В браузере поля сбрасываются, если код истёк (15 мин).

**Защита**

- Коды в БД — **SHA-256 хеш** (не открытый текст)
- Коды генерируются через `crypto.randomInt`
- Пароли — **bcrypt** (12 раундов)
- Сессия — **JWT** (HS256, `AUTH_SECRET`) в httpOnly-cookie `enter_session`; `jti` = id строки в таблице `sessions` (можно отозвать при выходе)
- OAuth Google — подписанный **state** (JWT + `AUTH_SECRET`)
- **Rate limit** на отправку кода, проверку, вход
- Автоочистка просроченных кодов и сессий при каждом auth-запросе
- После сброса пароля — **все сессии пользователя удаляются**
- Не более **10 активных сессий** на аккаунт
